Panel Controller

Version {{VERSION}}. Type a word or an error code in the box on the left. Clicking an error code in the app opens this page at that code.

What it does

Checks the theme CSS and JS files before they are pasted into the panel, and records the changes with git.

The appBacks up, builds, validates, compares with live, copies files to the clipboard, sends to git.
YouWrite the code, open the slot in the panel, paste and save.
Why is uploading manual? The PlatinMarket API (Reform API) has no endpoint for theme CSS and JS files. The app cannot send a file to the panel; it copies the files to the clipboard in order.

Installation

  1. Run Panel Controller-<version>.exe. No administrator rights and no Java needed.
  2. On first start the Setup screen opens. Use Choose folder to pick the folder that contains kaynak/.
  3. Enter the store CDN address: https://platincdn.com/<store no>/tema/%s, then Test and save. The address is saved only if a file can be read from it.
  4. Change the language and theme in Settings if you like.

Both settings are required. Until they are done, Publish, Restore and Git show the Setup screen. Both can be changed later in Settings.

CDN address: the address containing tema/genel.css in the store page's source, with %s in place of the file name.

Daily workflow

  1. Publish → Prepare. Backup, build and panel simulation run. All three steps should turn green. If one is red, click the code on the activity card and fix it; do not upload.
  2. Compare with live (runs on its own after Prepare). different files are the ones to upload.
  3. Upload wizard. Copies the different files to the clipboard in order and names the slot for each.
  4. After the wizard the comparison runs again. All should be same. If not, see cache.
  5. Check the browser console on the site. Only errors from platincdn.com/…/tema/ are ours.
  6. Git → commit and push.

Upload wizard

Takes only the files that are different from live. Order: page slots first (anasayfa, kategori, urun, sepet), the general slot last. The general slot affects every page, so it goes last.

  1. The file is copied to the clipboard.
  2. Open the named slot in the panel, delete its content (Ctrl+A, Delete), Ctrl+V, save.
  3. Pasted, next. On the last step Pasted, finish; the comparison runs again.

If the last backup is older than 2 hours, the wizard asks first: Back up now and continue, Continue without backup or Cancel.

Copy the file from the app, not from an editor. An open editor tab can show old content.

Restore

  1. The top backup is the live state just before the last upload.
  2. Copy to clipboard next to the file.
  3. Open the same slot in the panel, delete its content, paste, save.
  4. Publish → Compare with live.

Git

Tick the files, write a short message, Commit. The message goes out like this:

13.11.2026-Cuma-14.05 fixed the cart notice -p

Panel Controller ile gönderildi: https://github.com/wreazy-cs/panel-controller

-p: sent from Panel Controller (the date part follows the project's Turkish convention). The author is your own git account.

Push runs build and validate first; if they are not clean, nothing is pushed (PC-405). A push does not upload anything to the panel.

Source file rules

The first line of every piece is a meta line:

/*@vt 25 | SEARCH BAR | ezer: skin/css/header.css > #urun_arama_form */

25 is the piece number and must be unique across all slots. To find which piece a rule came from: Publish → Single step → Review copy, then search IC-VT-25 in veri/uretilen/okunur/.

If a change does not show

  1. Ctrl+Shift+R on the page, then a private window.
  2. Publish → Compare with live. If same, the upload is right and the browser cache is the problem.
  3. If different, the file was not saved or went into the wrong slot.

Questions

I pushed, but the site did not change

A push only records the change on GitHub. Uploading to the panel is done with Publish → wizard.

Why does the app not upload to the panel itself?

The PlatinMarket API has no endpoint for theme CSS and JS files.

Unexpected token '}' in the console

Comes from the platform's own code on the home page for signed-in users. Only errors from platincdn.com/…/tema/ are ours.
